# Transfer PHS Award Simulator

An interactive tool for modeling Presidential Honors Scholarship (PHS) awards
for transfer students at New College of Florida.

**Live site:** https://greeshma0218.github.io/transfer-phs-simulator/

## What it does
- Editable award table by transfer category and GPA band (Transform AA,
  Upper/Mid-Level Transfer, and the under-30-credit group that follows the
  FTIC GPA × Test grid)
- Editable Deposited and Enrolled student counts per row
- Live KPI cards showing students modeled, actual PHS spend, projected
  spend under the current award table, and variance vs. actual

## Notes
- Counts and actual spend figures are pre-filled from the Fall 2026
  Deposited and Enrolled transfer exports.
- Built as a standalone HTML/CSS/JS file — no build step or dependencies.
